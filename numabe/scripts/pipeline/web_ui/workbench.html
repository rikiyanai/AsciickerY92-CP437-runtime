Game Layout Guide

Standard layouts:
1 dir: static props, items
4 dir: S, W, N, E (RPG)
8 dir: S, SW, W, NW, N, NE, E, SE
Common frame counts:
Idle: 1 frame
Walk: 8 frames (per direction)
Attack: 6-12 frames
Death: 4-8 frames
Frames field accepts comma-separated for multiple anims: 1,8 = 1 idle + 8 walk

How to use the Workbench:
  1. Upload a sprite sheet image (or it loads from the wizard). Use + Add Source to merge additional images without replacing the current extraction.
  2. Find Sprites auto-detects sprites, or Draw Box to manually select regions
  3. Set Directions (angles) and Frames per direction, then click Lay Out Grid
  4. Drag drawn boxes from the source image onto grid cells in the center panel to place them
  5. Click a grid cell to select it, then use Swap, Duplicate, Import, or Transforms
  6. Use Animation Preview (right panel) to check the result, then Export .xp
Keyboard: Ctrl+C/V = copy/paste cells | Ctrl+Z/Y = undo/redo | Delete = remove selected box | Escape = exit draw mode
