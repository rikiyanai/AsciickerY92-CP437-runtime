How the 4-Track Pipeline Works

The pipeline ran your image through multiple detection and processing strategies in parallel. Each column below is a pipeline stage. Each card is one branch — a different result from a different strategy. Compare the thumbnails, then click Use this result on the one you like best, or Download any artifact directly.

Download All grabs every branch output as a ZIP so you can compare them side-by-side in your own tools.

pp_fft
Grid detected via FFT (frequency analysis) — best for regular, uniform grids
pp_gradient
Grid detected via gradient edges — best for hand-drawn or irregular grids
extractor_flood
Sprites extracted via flood-fill segmentation — finds connected color regions
extractor_bbox
Sprites extracted via bounding-box detection — finds rectangular sprite bounds
standard
Standard pixel-to-cell conversion — balanced quality/speed
quality
Subcell dithering with error diffusion — highest fidelity, slower
literal
1:1 pixel-to-cell mapping — only works when source is already 1px per cell
