Reflection
Why reflections? The game engine renders a dimmed "shadow" copy of every multi-angle sprite (used for isometric ground reflections). It does this by storing the original frames in the left half of the sheet and a dimmed copy in the right half, doubling the sheet width. Single-angle or flat sprites (angles = 1) skip this.
Detects if the sheet already has reflections by comparing left/right half brightness. If not found, generates them automatically.

Troubleshooting

Sprites look stretched? Check that cell width/height match your sprite grid.

Colors look wrong? Try Quality mode for better color matching.

Too many branches? Lower max_branches_per_stage in Advanced settings, or set a specific process mode instead of Auto.

Nothing detected? Make sure the background color or alpha threshold is set correctly.
